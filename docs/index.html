AI Tool Index

Which tools do AI assistants actually recommend? Measured every day, published weekly, raw answers included. Edition of 2026-08-31, covering 4 daily measurements.

The same fixed set of buyer questions goes to an AI assistant every day, and we record which tools its answer cites — not which ones rank on Google, and not which ones pay for placement. A tool scores one point per answer that linked to it. Nothing is weighted and no model judges the ranking: a link either appeared or it did not.

Why daily measurements and a weekly number. On 28 August 2026 the same questions were run twice, a few hours apart. Four of six tools moved, and the category leader swapped. One snapshot is noise dressed up as a ranking, so the published figure pools a week of daily answers instead.

Disclosure. This index is produced by the maintainer of two of the tools listed below, using one of them (an AI-citation tracker) as the measuring instrument. Both scored zero in this edition. The questions and the raw JSON are published so you can re-run the whole thing and check.

Method

Engine: Perplexity (agent mode), one sample per question per day, US market, English. Window: 4 days ending 2026-08-31. Platform cost of this edition: $0.0418.

  • The question set is fixed in categories.json and changes between editions only, never within one.
  • A tool matches when a cited URL matches its published pattern. Matching is a plain regular expression, not a model judgement.
  • Every day's raw answers and citation lists are committed under data/daily/.
  • One engine, for now. The series is the point; a single day is not.

What this does not measure: quality, price, reliability, or whether a tool is right for you. It measures visibility inside AI answers, which is a different thing and worth knowing precisely because it is different.
